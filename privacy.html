Privacy Policy

Last updated: 9 November 2026

Daily Shorts Uploader ("the tool") is a personal tool run by the owner of the BussinFACTS YouTube channel on their own computer. This policy explains what the tool does with data.

YouTube API Services

The tool uses YouTube API Services to upload videos to the owner's own YouTube channel. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • OAuth access to the owner's own Google account, limited to the scopes youtube.upload (to upload videos) and youtube.readonly (to read the owner's own channel name and the status of videos it uploaded).
  • The channel name, and the ID, privacy status and publish time of the videos the tool uploaded.

The tool does not access, collect, store or share data about any other YouTube users, viewers, comments, subscribers or analytics.

How data is used and stored

  • The OAuth token is stored only on the owner's own computer, in a private file readable only by the owner. It is never sent anywhere except Google's servers.
  • A local log keeps the ID, link and title of each video the tool uploaded, so it uploads at most one video per day.
  • No data is sold, shared with third parties, used for advertising, or combined with other data.
  • The narration text of each video (written by the tool, containing no personal data) is converted to speech using Microsoft's text-to-speech service.

Deletion and revoking access

  • Access can be revoked at any time at Google Account → Security → Third-party apps with account access (security.google.com/settings/security/permissions).
  • Deleting the tool's folder deletes the stored token and logs immediately. Locally stored API data is refreshed or deleted within 30 days as required by the YouTube API Services Developer Policies.
  • To request deletion of any data, email mujtabashahzadarif1980@gmail.com; requests are completed within 7 days.

Cookies

The tool and this website do not use cookies or tracking.
