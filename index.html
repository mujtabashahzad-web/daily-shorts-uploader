Daily Shorts Uploader

The private tool behind the BussinFACTS YouTube channel. Every day it creates one original, 3D-animated, fact-checked educational Short on the owner's own computer and uploads it to the owner's own channel using the YouTube API Services.

What it does
  1. Writes a short script about a curious science or history fact and checks it against reputable sources.
  2. Renders original 3D animation, captions and narration locally.
  3. Uploads the finished video, with its title, description and tags, to the owner's channel only (YouTube Data API videos.insert), and confirms the upload (videos.list, channels.list).

It is used by one person (the channel owner) and has no other users, no accounts, no ads and no payments. It does not read, collect or analyse any other YouTube users' data.
